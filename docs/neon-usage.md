# Neon 무료 요금제 사용량 절감

2026-10-14 기준 Production 프로젝트 small-lab-37274308의 10월 전송량은 4,087,226,945바이트(약 4.09GB), Free 한도 5GB의 약 82%였다. 요금제·인증·DB 자료는 변경하지 않았다. 사용량은 월 누계라 최적화 후에도 이미 쓴 양은 줄어들지 않는다.

## 원인과 변경

- 기존 상세·목록·홈·RSS·사이트맵이 `publishedArticles()`를 호출해 전체 기사 본문과 rich document를 읽었다. 제목 메타데이터와 상세 렌더링도 각각 같은 전체 조회를 실행했다. 통계에서 전체 조회 24회 / 반환 2,952행을 확인했다.
- 공개 화면은 Next Data Cache에 15분 동안 데이터를 공유한다. `force-dynamic`은 명시적 데이터 캐시까지 우회하므로 공개 경로에서 제거하고, 날짜와 요청 시점이 필요한 경로에는 `connection()`을 사용했다. 관리자·로그인·비밀번호 조회는 캐시하지 않는다.
- 상세는 해당 ID 한 편만 읽고 React 요청 메모로 메타데이터와 공유한다. 관련 글은 요약 3편만 읽는다.
- 홈은 각 블로그 카테고리 4편, 뉴스 3편, 예정 동호인 대회 3편과 개수만 조회한다. 목록은 24편씩 페이지를 나눈다. 카드용 SQL JSON projection에는 본문·rich document·경기 결과·사진 권리 설명이 없다. 본문 검색은 DB 안에서 처리하며 `%`·`_`는 검색 와일드카드로 취급하지 않는다.
- RSS는 최신 30편의 필요한 필드만, 최대 5편씩 캐시해 Next의 2MB 항목 제한을 피한다. 사이트맵은 ID·날짜·사진 URL만 읽고 전체 목록을 500편 단위로 조회한다.
- 자동 발행의 변경 전 조회·백업도 해당 배치 ID로 제한한다. 편집 검토용 전체 snapshot은 유지한다.

현재 DB에서 전체 JSON은 771,402바이트였고 새 목록 첫 페이지 projection은 17,558바이트였다. 약 97.7% 감소는 **해당 쿼리의 반환 데이터 비교**이며 전체 월 사용량 감소율을 뜻하지 않는다. 관리자 이용, 자동 편집 snapshot, 캐시 최초 조회·만료·갱신은 여전히 전송량을 사용한다.

## 갱신과 검증

관리자 저장은 public-articles 태그와 공개 페이지 경로를 즉시 갱신한다. 자동 발행 스크립트는 DB 검증 후 기존 SESSION_SECRET으로 서명한 POST를 `/api/editorial/revalidate`에 보낸다. 비밀 값은 요청에 포함하지 않으며 5분 이내 타임스탬프와 HMAC 서명이 모두 맞아야 실행된다. 실패 시 게시를 다시 실행하지 말고 갱신 요청만 재시도한다. 타임아웃 등으로 실패하면 15분 캐시 간격 뒤 들어오는 요청에서 백그라운드 재조회하므로 그때 첫 응답은 이전 내용일 수 있다. RSS의 브라우저/CDN 응답 캐시는 최대 5분이다.

회귀 검사: `npm run build` 후 `node scripts/test-public-cache.mjs --suite`. 임시 로컬 기사와 테스트 전용 인증으로 공개 캐시 재사용, 관리자 최신 조회, 저장·자동 갱신·비공개 전환, 페이지 분할, 본문 검색, 초안·예시 숨김, RSS·사이트맵을 확인한다. 운영 DB 글을 수정하지 않는다.

참고: https://neon.com/docs/introduction/network-transfer — 무료 한도는 프로젝트별 월 5GB이며 다음 결제 기간에 재설정된다.
