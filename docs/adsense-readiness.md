## 사진 사용 근거 점검

뉴스의 실제 사진은 공개 라이선스와 시점 표시가 있으며, 초기 코트 일러스트는 자체 생성 표시가 있다. 장비 19편의 제품 사진은 제조사/유통사 사진을 제품 식별과 비평에 제한적으로 인용한 자료다. 공개 URL이나 출처 표시는 허가·라이선스로 간주하지 않는다.

이 사진들의 **별도 재사용 허가가 확보됐다고 주장하지 않는다**. Google 승인이나 적법성을 자동으로 판정한 것도 아니다. 제품 사진을 일반 광고 소재로 재사용하거나, 제품 비평과 무관한 화면에 복제하지 않는다. 개별 사용의 인용 범위를 벗어나거나 권리 문제가 확인되면 대체·삭제·게시 중단한다. 운영자에게 권리 관련 문의가 도착하면 해당 자료와 원문을 대조한다.

신규 장비 글은 직접 소유한 실물 사진, 명시적인 사용 허락, 상업적 사용 가능한 라이선스를 우선한다. 제한 인용만 근거로 사용하는 사진은 별도로 검토하며 자동으로 ‘사용 허가 확인’ 처리하지 않는다. 허가가 필요한 자료를 확보하지 못하면 사진을 만들어 실물처럼 소개하지 않고 해당 글을 보류한다.

## 계정 연결·신청 상태

### 2026-10-27 상태 확인

운영자의 심사 현황 문의에 따라 Gmail과 해당 계정의 AdSense 사이트 상세 화면을 읽었다. **현재 승인 상태는 ‘주의 필요’, 사유는 ‘가치가 별로 없는 콘텐츠’**다. 사이트 목록의 최종 업데이트는 **2026-10-22 오전 10:45 KST**이며, 같은 시각 Google AdSense의 수정 요청 메일이 도착했다. 확인 당시 해당 메일은 읽지 않은 상태로 휴지통에 있었다. 누가 또는 어떤 규칙이 메일을 이동했는지는 확인하지 않았다.

AdSense 상세 화면에는 콘텐츠의 고유 가치, 고품질 정보, 지속적인 큐레이션·유지관리와 실제 사용자 관심을 점검한 뒤 재검토를 요청하라는 안내가 있다. 개별 문제 글이나 사진이 특정된 것은 아니다. **Ads.txt 상태는 ‘승인됨’**으로 표시되지만 사이트 광고 게재 승인을 뜻하지 않는다. 오늘은 상태 조회만 했으며 문제 수정 확인 체크·검토 요청 제출·광고 활성화·이메일 복원은 하지 않았다.

### 2026-10-13 최초 신청 기록

2026-10-13 운영자의 신청 지시에 따라 `baekhyunjin@gmail.com`의 기존 AdSense 계정 `pub-9783991407242334`를 재활성화하고 `mintontoday.com`을 등록했다. 사이트에 계정에서 발급한 `google-adsense-account` 메타 태그와 ads.txt를 배포한 뒤 Google의 소유 확인 성공을 확인했다. 검토 요청을 제출했으며 화면에 **‘사이트의 광고 게재 가능 여부 검토 중’**, **‘모든 단계를 완료했습니다’**가 표시됐다. 이것은 신청 접수이며 승인 완료가 아니다. 광고 스크립트·실제 광고는 활성화하지 않았다.

1. 사이트 등록 완료. 기존 계정의 지급 단계는 ‘정보를 확인했습니다’ 상태다. 신규 지급 정보·신분 정보는 입력하지 않았다.
2. 소유 확인 완료. `<meta name="google-adsense-account" content="ca-pub-9783991407242334">`가 공개 페이지의 head에 포함된다. Search Console·네이버 확인 태그도 유지했다.
3. `/ads.txt`에 `google.com, pub-9783991407242334, DIRECT, f08c47fec0942fa0`를 제공하며 실제 도메인의 HTTP 200과 본문을 확인했다. AdSense의 ads.txt 상태 표시는 크롤링 후 갱신될 수 있다.
4. 광고 활성화 전에 개인정보 페이지의 적용 상태를 갱신하고 광고/동의 설정을 실제 동작과 맞춘다. EEA·영국·스위스 방문자에 대한 Google 인증 CMP는 Google 개인정보 보호 및 메시지 등 인증된 서비스를 사용한다. 자체 제작 ‘동의’ 버튼으로 인증 CMP를 대신하지 않는다.
5. 운영자/검색 결과 없음/404/예시 등 광고 부적합 화면을 제외한다. 자동 광고를 사용하면 계정의 페이지 제외 설정도 검토한다. 현재 광고 컴포넌트는 페이지에 마운트되지 않는다.
6. 심사 요청 제출 완료. 후속 정책 알림·검토 결과에 따라 필요한 수정을 진행한다. 심사 결과나 수익을 보장하지 않는다.
