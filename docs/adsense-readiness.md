- 문의 이메일: `baekhyunjin@gmail.com`. 문의·소개·개인정보·편집 원칙에 표시하고 `mailto:` 링크를 제공한다.
- 소개 페이지에 발행·문의 담당과 독립 운영 사실을 표시한다. 확인하지 않은 운영자의 경력·자격·법적 실명은 만들지 않는다.
- 개인정보 페이지의 개발 미리보기·연락처 준비 중 문구를 제거한다. 글 저장의 로컬 저장소, 운영자 세션, Gmail 문의, 외부 글꼴/사진, Vercel/Neon 처리 범위를 실제 구현과 맞춘다.
- 현재 광고·분석 추적 도구가 활성화되지 않은 상태를 표시한다. 향후 AdSense의 제3자 쿠키·웹 비콘·IP/식별자 처리, Google의 데이터 사용 안내, 개인 맞춤 광고 설정, 해당 지역의 인증 CMP 요건을 안내한다.
- 짧은 창간 뉴스 5편을 같은 ID와 실제 발행일에서 재편집한다. 원문에 없는 경기·인터뷰·취재 경험을 만들지 않고 작성 업무 설명을 줄인다.
- 자료사진의 연도/행사, CC 저자·라이선스·변경 표시와 AI 이미지 표시를 유지한다. ‘이 현장 사진이 아니다’라는 반복 설명은 제거한다.
- 장비 글의 중복 자료 기반 안내는 본문 끝으로 모은다. 외부 후기만 비교한 글을 직접 사용한 리뷰로 소개하지 않는다.
- 실제 발행 글에서 개발용 예시 6건은 기존 게시 필터에 따라 계속 제외된다. 원고 수와 길이만으로 승인을 보장하지 않는다.

## 사진 사용 근거 점검

뉴스의 실제 사진은 공개 라이선스와 시점 표시가 있으며, 초기 코트 일러스트는 자체 생성 표시가 있다. 장비 19편의 제품 사진은 제조사/유통사 사진을 제품 식별과 비평에 제한적으로 인용한 자료다. 공개 URL이나 출처 표시는 허가·라이선스로 간주하지 않는다.

이 사진들의 **별도 재사용 허가가 확보됐다고 주장하지 않는다**. Google 승인이나 적법성을 자동으로 판정한 것도 아니다. 제품 사진을 일반 광고 소재로 재사용하거나, 제품 비평과 무관한 화면에 복제하지 않는다. 개별 사용의 인용 범위를 벗어나거나 권리 문제가 확인되면 대체·삭제·게시 중단한다. 운영자에게 권리 관련 문의가 도착하면 해당 자료와 원문을 대조한다.

신규 장비 글은 직접 소유한 실물 사진, 명시적인 사용 허락, 상업적 사용 가능한 라이선스를 우선한다. 제한 인용만 근거로 사용하는 사진은 별도로 검토하며 자동으로 ‘사용 허가 확인’ 처리하지 않는다. 허가가 필요한 자료를 확보하지 못하면 사진을 만들어 실물처럼 소개하지 않고 해당 글을 보류한다.

## 계정에서 해야 하는 연결 단계

사이트 수정을 애드센스 신청 완료로 설명하지 않는다. 현재 계정 게시자 ID가 제공되지 않았으며 소유 확인 코드·광고 스크립트·실제 광고는 새로 활성화하지 않았다.

1. Google AdSense 계정에서 `mintontoday.com`을 등록한다. 계정 자격과 신청자의 성인 여부 등은 계정에서 확인한다.
2. 계정이 제공하는 소유 확인 방법(메타 태그/코드/ads.txt 중 제공되는 방법)을 정확한 게시자 ID로 적용한다. Search Console 소유 확인과 AdSense 확인은 서로 다른 절차다.
3. 게시자 ID로 `ads.txt`를 설정한다. 현재 `/ads.txt`는 광고 비활성화 주석만 반환한다. `ads.txt`는 권장 사항이며 없는 사실만으로 사이트 부적격이라고 단정하지 않는다.
4. 광고 활성화 전에 개인정보 페이지의 적용 상태를 갱신하고 광고/동의 설정을 실제 동작과 맞춘다. EEA·영국·스위스 방문자에 대한 Google 인증 CMP는 Google 개인정보 보호 및 메시지 등 인증된 서비스를 사용한다. 자체 제작 ‘동의’ 버튼으로 인증 CMP를 대신하지 않는다.
5. 운영자/검색 결과 없음/404/예시 등 광고 부적합 화면을 제외한다. 자동 광고를 사용하면 계정의 페이지 제외 설정도 검토한다. 현재 광고 컴포넌트는 페이지에 마운트되지 않는다.
6. 운영자가 공개 글과 사진 사용 근거를 최종 확인하고 심사를 요청한다. 심사 결과나 수익을 보장하지 않는다.
