# 2026.09.27 아침 편집·발행 기록

승인된 블로그 글은 총 2편이다. 최근 순환을 고려해 장비 이야기와 코트 라이프를 각각 1편씩 발행했다. 공백 제외 본문은 각각 2,296자와 2,069자다. 뉴스 1건을 새로 게시하고 국가대표 대회 고정 글의 결과·일정 기록을 갱신했다.

- 장비 이야기: [빅터 THRUSTER RYUGA II J 리뷰: 3U·4U와 실제 시타감 비교](https://mintontoday.com/articles/gear-victor-ryuga-ii-review-20260927). 일본 공식 제품 사양과 시타 라켓 제공 사실을 공개한 C.K. Yew 리뷰, 중국 배드민턴 커뮤니티의 3U·4U 사용 후기를 비교했다. 직접 시타하지 않은 자료 기반 리뷰라고 명시했다. 제품 식별·비평 목적의 공식 제품 사진 두 장을 사용했다.
- 코트 라이프: [배드민턴 복식 파트너와 첫 게임 전 맞출 3가지: 가운데·위치·콜](https://mintontoday.com/articles/court-doubles-partner-calls-20260927). 복식 파트너 간 가운데 공 처리, 전후·좌우 위치 전환, 짧은 콜을 다루고 공식 규칙과 모임별 약속을 구분했다. 새 AI 생성 일러스트를 사용하고 캡션에 표시했다.
- 뉴스: [안세영·유태빈, 아시안게임 8강행…유태빈은 시위치 제압](https://mintontoday.com/articles/news-an-yoo-asian-games-qf-20260927). 조직위 공식 점수표에서 9월 26일 안세영과 유태빈의 2승 및 유태빈의 시위치전 승리를 확인해 경기 배경과 다음 대진을 정리했다. 자료 사진은 2019년 경기 사진임을 캡션에 밝혔고, De-Shao Liu / Wikimedia Commons, CC BY-SA 4.0으로 표기했다.
- 국가대표 대회: [2026 아시안게임 배드민턴 일정·결과: 한국 대표팀 경기와 다음 대진](https://mintontoday.com/articles/tournament-asian-games-2026)을 갱신했다. 9월 26일 결과와 9월 27일 한국 대표팀 7개 대진을 공식 일정표 기준으로 반영했다. 게시 직전 확인 시 27일 대진은 모두 START_LIST였으며 표시 시각은 주최 측 일정상의 예상 시각으로 다뤘다.

국내 동호인 대회는 [배드민톡 공개 일정 인덱스](https://badmintok.com/badminton-tournament/)와 가까운 서울·경기 일정의 주최 측 안내를 확인했다. 광주시협회장배와 노원구협회 대회의 공식 요강 PDF 및 10월 3일 전후 일정에서 기존 글을 바꿀 만큼 확인된 일정 정정·취소는 찾지 못해 고정 글은 그대로 두었다. 광주 대회 접수 마감 안내에는 기존 자료 간 차이가 있어 새 주최 측 확인 없이 임의 수정하지 않았다.

## 검증

- 게시 전 Production 스냅샷 75건에서 9월 27일 중복 글이 없고 대회 고정 글의 guarded hash가 예상값과 일치하는 것을 확인했다.
- 스키마 검증 후 Production DB에 새 글 3건과 대회 글 1건을 반영했다. 결과는 written 4, skipped 0이며 게시 직후 DB 재검증을 통과했다.
- 게시 후 Production 스냅샷은 전체 78건, daily-editor 관리 공개 글 72건이다. 관리 글 카테고리는 레슨 8건, 코트 라이프 9건, 장비 8건, 뉴스 9건, 대회 38건이다. 네 게시물의 검색 태그가 저장된 것도 확인했다.
- 새 코트 라이프 이미지를 포함한 GitHub 커밋 `105bc4a`의 Vercel Production 배포가 READY인 것을 확인한 후 DB 게시를 진행했다. 네 게시 페이지는 각각 HTTP 200을 반환했고 제목도 확인했다. 새 AI 이미지와 빅터 제품 사진 두 장은 HTTP 200, image/webp를 반환했다.
- 전날 실행 기록의 카테고리 합계 문구를 Production 스냅샷 수치에 맞게 바로잡았다. 이번 확인은 공개 대회 인덱스와 가까운 일정의 요강을 표본 확인한 것이며 서울·경기 모든 협회 채널을 전수 확인한 것은 아니다.
