# 2026-11-10 애드센스 재심사 제출과 뉴스 정비

운영 스냅샷의 공개 뉴스 25편을 비교하고 경기 맥락이 빠진 짧은 기사 세 편을 보강했다. 대상은 모두 `daily-editor` 소유였고 수정 직전 해시를 확인했다.

- [안세영을 주목한 AP](https://mintontoday.com/articles/news-ap-an-se-young-20260917). 개막 전 소개 두 문장에 파리 올림픽 결승과 아시안게임 단체전·개인전 기록을 보강했다. AP의 개막 전 전망과 조직위원회가 발표한 경기 뒤 결과를 구분했다.
- [한국 여자단체 말레이시아전](https://mintontoday.com/articles/news-an-se-young-asian-games-20260922). 첫 단식만 있던 기사에 네 경기의 흐름, 김가은의 두 번째 단식, 김혜정·정나은의 최종 게임 24–22를 보강했다. 조직위원회와 연합뉴스 현장 보도를 대조했다.
- [서승재·김원호의 아시안게임](https://mintontoday.com/articles/news-seo-kim-asian-games-confidence-20260921). 현지 인터뷰 직전 홍콩전의 경기 결과와 개인전 8강 역전승, 4강 패배와 동메달을 보강했다. 31분은 현장 보도에 귀속하고, 단체전 팀 결과와 개인전 메달을 구분했다.

기존 주소·최초 발행일·사진·사진 사용 조건을 유지했다. 뉴스 원고 세 편이 수치·인용·서법과 발행 스키마를 통과했고 운영 DB에서 재검증됐다. 캐시 갱신 후 공개 URL 세 곳의 HTTP 200, 전체 본문, canonical, 사이트맵, `NewsArticle` 제목·작성 기관·발행일·수정일·이미지·인용 출처를 확인했다. 기사 사진 네 장의 응답도 모두 HTTP 200이었다. Chrome에서 말레이시아전 기사 제목과 실제 JSON-LD가 일치했다.

운영 페이지 확인 뒤 로그인된 애드센스에서 `mintontoday.com`의 수정 완료 확인란을 선택하고 검토 요청을 한 번 제출했다. 결과 화면에 사이트와 함께 ‘사이트의 광고 게재 가능 여부 검토 중’, ‘모든 단계를 완료했습니다’가 표시됐다.
