# 2026.09.24 오전 편집·발행 기록

오늘 새 블로그는 총 2편으로 제한했다. 레슨·장비·코트 라이프 순환에 따라 장비 이야기와 코트 라이프를 각각 1편 발행했다. 두 본문은 공백 제외 각각 2,089자와 2,102자다.

- 장비 이야기: [요넥스 65Z3·65Z4 배드민턴화 비교](https://mintontoday.com/articles/gear-yonex-65z3-vs-65z4-shoes-20260924). 요넥스몰·요넥스 공식 사양, Yonex 2025년 출시 소개, 공개된 직접 착화 후기 2건과 품질 안내를 구분해 정리했다. 직접 착화한 리뷰가 아님을 표시했다. 세대가 다른 65Z3·65Z4 공식 상품 사진 2장을 각 제품 출처와 함께 넣었다.
- 코트 라이프: [복식 콜과 파트너 약속](https://mintontoday.com/articles/court-doubles-communication-calls-20260924). BWF 규칙 13.3.8과 동호회에서 정해 쓸 수 있는 콜 예시를 분리했다. 사진은 Wikimedia Commons의 실제 복식 경기 사진이며 CC BY-SA 4.0 조건과 저작자를 표시했다.
- 뉴스: [한국 여자단체 준결승 결과](https://mintontoday.com/articles/news-korea-japan-semifinal-preview-20260923). 경기 전 예고를 한국 1–3 일본의 경기별 결과와 동메달 소식으로 고쳤다. Yonhap과 아시안게임 조직위원회 결과 시스템을 확인했다. 사진은 2019 중국 타이베이 오픈의 안세영 경기 자료 사진으로 바꾸고, 2026년 아시안게임 사진이 아님을 캡션에 표시했다. 저작자와 CC BY-SA 4.0 라이선스도 기재했다.
- 국가대표 대회: [아시안게임 배드민턴 관전 노트](https://mintontoday.com/articles/tournament-asian-games-2026)를 갱신했다. 9월 23일 여자단체 준결승 한국 1–3 일본 결과와 9월 24일 여자 결승 중국–일본, 남자 결승 인도네시아–중국 일정을 반영했다. 공식 결과 시스템은 09:38 KST 확인 당시 여자 결승 Running·팀 점수 0–0, 남자 결승 Scheduled로 표시했다. 09:41 재확인에서도 여자 결승은 Running·0–0이었다. 진행 중 점수를 최종 결과로 쓰지 않았다.

기존 daily-editor 관리 글 59편에 주제별 해시태그를 추가했고, 뉴스·대회 갱신 글에도 각각 태그를 반영했다. 그 결과 기존 관리 글 61편과 오늘 신설한 2편 모두 태그가 있는 상태로 확인했다. 편집 권한이 지정되지 않은 시드·예시 글 6편은 건드리지 않았다.

국내 동호인 대회는 최신 공개 일정 목록과 확인 가능한 주최 측 공지(배드민턴프렌즈, 부천시체육회)를 살폈다. 새로 확인된 공식 변경 공지는 없어 기존 서울·경기 행사 게시물을 수정하지 않았다. 모든 지역 협회 채널을 빠짐없이 확인했다는 뜻은 아니다.

## 검증

- scripts/editorial-publish.mjs의 Production snapshot → schema validate → guarded publish 절차 사용.
- Production DB에 63건 반영(기존 글 태그 59건, 뉴스·대회 갱신 2건, 새 블로그 2건), 건너뜀 0건. 게시 후 기사 스키마 검증 통과.
- Production DB 전체 69건, daily-editor 관리 63건이며 관리 글 중 태그 누락 0건을 재확인.
- 신규 글 2건과 갱신 뉴스·대회 글 2건의 공개 페이지가 HTTP 200을 반환했다. 제품 사진 2장, CC BY-SA 사진 2장의 HTTPS 이미지 주소도 응답을 확인했다.
