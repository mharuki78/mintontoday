# 2026-09-22 창간 콘텐츠 확충

사용자가 요청한 일회성 초기 콘텐츠 확충. 정기 발행은 기존대로 매일 한국 시간 09:00에 블로그 총 2편(세 카테고리 순환), 뉴스·대회 변경 사항 확인을 유지한다.

## 발행 결과

- Production 데이터베이스에 신규 52편, 기존 5편 수정. 해시 충돌·건너뛴 글 없음. 트랜잭션 후 57편을 다시 읽어 스키마 검증 완료.
- 실제 공개 글 총 58편: 레슨 5, 장비 5, 코트 라이프 5, 뉴스 5, 국가대표·국제대회 5, 서울·경기 동호인 대회 33. 기존 예시 글 6개는 계속 비공개 처리되는 목록 정책을 유지한다.
- 블로그 세 카테고리는 각각 9월 17~21일 창간 기획 연재일을 배정했다. 실제 발행일과 구조화 데이터의 `datePublished`는 9월 22일이다. 뉴스는 별도 원문 보도·기록 기준일을 표시한다.
- 레슨 5편은 모두 공백 제외 2,000자 이상. 장비 5편은 각기 다른 실제 제품 사진 2장 이상, 출처·제공처·인용 설명을 포함한다. 자료 기반 리뷰임을 명시하며 직접 사용 경험을 꾸미지 않았다.

## 대회 조사 범위와 정정

배드민톡의 공개 대회 목록에서 향후 서울·경기 후보 31건을 추려, 각 상세 공지의 홍보 포스터를 직접 대조했다. 같은 서울시민리그 포스터에 있는 12월 6일 본선을 별도 안내로 추가하고 기존 서울마이소울 대회를 포함했다. 검색으로 확인 가능한 33개 일정이며 모든 비공개·미공지 대회까지 망라했다는 의미는 아니다.

- 요넥스 루키 머니컵: 목록의 10월 10일·서울 대신 주최 측 공문과 포스터의 10월 11일·경기 포천을 적용.
- 빅터 배프 머니컵: 가산체육문화센터 소재지에 따라 경기 포천으로 분류.
- 강동구협회장기: 실제 경기장이 남양주이므로 경기 지역에 표시.
- 한국건강관리협회장배: 포스터의 서울 마곡을 적용하고 대회와 맞지 않는 접수 링크를 제외.
- 광주시협회장배: 포스터와 목록의 접수 마감일 차이를 본문에 명시.
- 용산구청장기: 성심여중 체육관 미확정 표기를 유지.
- 서울시민리그 본선은 예선 진출 자격을 확인해야 하는 일정이며 일반 공개 접수로 표시하지 않음.
- 접수 마감 경과와 대회 종료를 구분. 개최 전 일정에는 결과를 만들지 않음.

각 글의 `sources`, `images.sourceUrl`, `event.url`에 근거를 저장했다. 배드민톡의 수록 자료와 주최 측 직접 공문을 구분해 표시했다. 국가대표·국제대회는 기존 아시안게임에 Arctic Open, Denmark Open, French Open, HYLO Open의 확인된 일정 4건을 추가했다. 향후 한국 선수 출전 명단은 미확정으로 명시했다.

## 검증

- 콘텐츠 배치 57편 스키마 검사 통과.
- 편집 정책 및 창간 콘텐츠 검사 7개 통과: 분량·사진·출처·수량·날짜 구분·한국 시간 날짜 경계·지난/취소/종료 대회 제외.
- TypeScript 및 Next.js production build 통과.
- 브라우저에서 홈페이지 카테고리별 5편, 동호인 대회 33개와 날짜순 정렬, 상세 일정과 출처를 확인.
- 390px 모바일에서 홈페이지 및 장비·대회 상세의 가로 넘침 없음. 장비 본문 사진 2장 로딩, 실제 발행일과 창간 연재일 표시 확인.
- 홈페이지에 분야별 글 모음, 최신 뉴스, 예정 동호인 대회 구역을 추가. 목록 및 관련 글에서 지난 동호인 대회를 제외한다.

영상 코너·대회 달력·입문 로드맵은 후속 제안이며 이번 발행에 구현하지 않았다.
