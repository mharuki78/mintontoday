# 2026.09.27 일회성 블로그 추가 발행

사용자 요청에 따라 오늘 정기 발행분 2편에 더해 블로그 2편을 한 번만 추가했다. 주제 중복과 최근 카테고리 수를 확인하고 레슨 & 가이드 1편, 장비 이야기 1편을 게시했다. 이후 자동 발행 수량은 기존 하루 총 2편을 유지한다.

- 레슨: [배드민턴 스매시가 네트에 걸릴 때: 타점과 다음 공을 함께 연습하는 법](https://mintontoday.com/articles/lesson-smash-net-contact-recovery-20260927-extra). BWF Shuttle Time 17차시의 몸 앞 타점, 스매시·블록 연계 연습과 Badminton Bible의 다음 공 준비 설명을 확인했다. 같은 피딩에서 네트 실수 원인을 나누는 30분 연습은 독자를 위한 자체 예시다. 공백 제외 본문 2,116자. 새 AI 일러스트 1장을 별도 표시했다.
- 장비: [요넥스 나노플레어 1000 Z 리뷰: 빠른 복식 라켓의 장점과 타점 부담](https://mintontoday.com/articles/gear-yonex-nanoflare-1000z-review-20260927-extra). 요넥스 공식 NF-1000Z 3U·4U 사양 및 출시 설명과 C.K. Yew, Paul Stewart의 실제 4U/G5 시타기를 대조했다. 빠른 반응이라는 공통점과 헤드 무게감에 대한 서로 다른 체감을 세팅·비교 라켓과 함께 설명했다. 직접 시타한 글이 아님을 표시했다. 공백 제외 본문 2,093자. 요넥스 공식 출시 사진과 공식 상품 사진, 서로 다른 실물 사진 2장을 제품 식별·비평 범위로 출처와 함께 사용했다.

## 검증

- 게시 전 Production 스냅샷 78건에서 오늘 정기 블로그 2편과 추가 글 ID 중복 없음, 두 추가 글의 expectedHash=null을 확인했다.
- `validate production`에서 2건 모두 통과했다. 새 일러스트를 포함한 GitHub 커밋 `89f5d19`의 Vercel Production 배포가 READY인 것을 확인한 뒤 DB 게시를 진행했다.
- `publish production --apply` 결과 written 2, skipped 0이고 DB 재검증을 통과했다. 게시 후 Production 스냅샷은 전체 80건, daily-editor 관리 공개 글 74건이다. 관리 글은 레슨·장비·코트 라이프·뉴스 각 9건, 대회 38건이다. 오늘 블로그는 정기 2편과 추가 2편으로 총 4편이다.
- 두 공개 글은 본문·이미지 주소·제목을 포함한 HTTP 200 응답을 반환했다. 레슨 새 이미지와 장비의 공식 사진 두 장도 HTTP 200 이미지 응답을 확인했다. 새 글에는 각각 6개와 7개의 검색 태그가 DB에 저장됐다.
